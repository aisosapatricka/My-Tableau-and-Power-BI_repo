# My-Tableau-and-Power-BI_repo
Tableau Data Visualisation Project
📊 Data Technician Bootcamp Project

This project was completed as part of my Data Technician Bootcamp, developing practical skills in Tableau, data visualisation, dashboard creation and data storytelling.


The project focused on transforming datasets into clear and interactive visualisations that can be used to identify trends, compare performance and communicate insights to an audience. The workbook included Tableau analysis using health and Spotify datasets, with dashboards designed to support data-driven decision-making.


🛠️ Skills Demonstrated
Interactive Dashboard Creation – combined multiple worksheets into a single dashboard to present key findings clearly
Filters and Interactive Controls – used filters such as Country, Continent, Year and Top N selections to allow users to explore the data
Calculated Fields – developed calculations and applied analytical techniques to transform and interpret data
Data Sorting and Filtering – identified the highest and lowest performing categories and focused analysis on relevant records
Data Storytelling – structured visualisations to communicate trends, comparisons and key findings rather than simply displaying raw data
Chart Creation
📊 Bar charts
📈 Line charts
🥧 Pie charts
🔵 Scatter plots
🗺️ Geographic/map visualisations
Dashboard Design – combined multiple visualisations, filters and titles into a clear analytical dashboard
Trend Analysis – analysed changes over time and compared categories, countries and groups
Comparative Analysis – explored relationships between different measures and categories
Tableau Public – published dashboards so that analysis could be shared and viewed interactively
📈 Tableau Analysis

The project involved creating visualisations such as Life Expectancy by Continent, Life Expectancy Trends, Population by Gender and Life Expectancy vs BMI. These were combined into a dashboard titled Global Health Insights.

🎯 Data Storytelling

A key focus of the project was learning how to turn data into a clear visual story.

Rather than presenting isolated numbers, I used charts, filters and dashboards to help users:

Identify important trends
Compare different categories
Explore data interactively
Spot patterns and differences
Understand key findings quickly
Use visual evidence to support business or organisational decisions
💡 Key Learning Outcome

This project strengthened my ability to use Tableau to transform raw data into interactive and meaningful visualisations.

It demonstrates my developing skills in data analysis, dashboard design, visual storytelling and communicating insights through data, providing a strong foundation for working with larger retail, sales and business datasets.
